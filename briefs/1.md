# Domain schemas (SPEC.md §1-3)

You are the builder for batch 1 of Anamnesis, a Python 3.12 project managed with uv. Work only inside this repository.

## Goal
Implement the Pydantic v2 domain models in `SPEC.md` §1–3 so that `tests/contract/test_b1_schemas.py` passes.

## Files to create
- `anamnesis/schema/__init__.py`: re-exports every public name the contract test imports.
- `anamnesis/schema/evidence.py`: `AudioTurn`, `ImageRegion`.
- `anamnesis/schema/medication.py`:
  - enums `Unit` (`mg, mcg, g, ml, iu`), `StrengthPer` (`tablet, capsule, ml, dose`), `MedicationStatus`, `Readability`
  - models `IngredientAmount`, `Strength`, `DoseRegimen`, `PatientClaim`, `PackObservation`
- `anamnesis/schema/findings.py`: `DiscrepancyType` and `Finding`, with the evidence-side rules from SPEC §3.
- `tests/unit/test_schema_extra.py`: a few extra edge-case tests of your own.

## Rules
- **Do not modify, rename or delete anything in `tests/contract/`. A batch that touches it is rejected automatically.**
- Enums are `str` enums with lowercase values. Member names are uppercase (`MedicationStatus.ACTIVE`, `DiscrepancyType.MISSING_MODALITY`).
- Every model uses `model_config = ConfigDict(extra="forbid")`. Use `Decimal` for amounts. IDs are non-empty strings.
- Cross-field rules go in `model_validator(mode="after")`, with clear error messages.
- `Finding` fields: `finding_id`, `type`, `claim_id: str | None`, `observation_id: str | None`, `audio_evidence: list[str]`, `visual_evidence: list[str]`, `needs_clinician_review: bool`, `clinician_note: str`, `patient_question_id: str | None = None`.
- No recursive models, no network, no new dependencies (pydantic and pyyaml are already installed).
- Keep the code small and readable: short docstrings and no speculative features.

## Done when
`uv run ruff check .` and `uv run pytest -q` both pass. Do not commit; the reviewer commits.
