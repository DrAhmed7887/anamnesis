# Provider adapters, offline (SPEC.md §1, §4, §5)

You are the builder for batch 4 of Anamnesis (Python 3.12, uv). Batches 1–3 built the domain schemas and the deterministic reconciler. This batch builds the **typed boundary** to Meta's models, with fixture adapters for offline replay. **No live network calls, no keys, no new dependencies.**

## Goal
Make `tests/contract/test_b4_providers.py` pass, keeping every other test green.

## Read first
- `docs/muse/muse-voice-transcribe.md`: JSON `turns[]` with `turnId`, `startMs`, `endMs`, `transcript`, `speaker`. Turn-level timing only, no confidence.
- `docs/muse/sam-3-1.md`: the "Output format" section. Records look like `<0f>{id}<|box;x1=..;y1=..;x2=..;y2=..;w=..;h=..[;c=..]|><|mask;...|>`, separated by commas. Corners are inclusive source pixels. Empty output means zero objects, which is valid.
- `docs/muse/meta-model-api.md` and `README.md` for the prices:
  - Spark: $1.25 per 1M input tokens, $4.25 per 1M output tokens
  - SAM: $2.50 per 1,000 images
  - Voice: $0.18 per audio hour, billed in whole seconds

## Package `anamnesis/providers/`
Export everything the contract imports from `anamnesis/providers/__init__.py`.

- **`base.py`**
  - `ProviderError(Exception)` with `__init__(provider, message, retryable=False)`, keeping `.provider` and `.retryable`.
  - `ProviderTrace`: a Pydantic model with `extra="forbid"` and fields `call_id` (non-empty), `model_id`, `latency_ms ≥ 0`, `input_tokens ≥ 0`, `output_tokens ≥ 0`, `cost_usd: Decimal ≥ 0`. **Reject any `model_id` ending in `-contributor`.**
  - `with_one_retry(fn)` calls `fn()`. On a retryable `ProviderError` it calls once more; otherwise it re-raises.
  - `cost_usd(model_id, *, input_tokens=0, output_tokens=0, audio_ms=None, images=None) -> Decimal`, using an explicit price table. Unknown models raise `KeyError`. Voice rounds up to whole seconds.
- **`spend.py`**
  - `SpendCapExceeded(Exception)`.
  - `SpendGuard(ledger_path, cap_usd)`: an append-only JSONL ledger (one line per charge: `call_id`, `model_id`, `cost_usd` as a string, UTC time).
    - `total_usd` is the sum of the lines, so it reloads from disk.
    - `check(estimate)` raises if `total + estimate > cap`.
    - `charge(trace)` checks, then appends. A refused charge is not written.
- **`voice.py`:** `parse_transcribe_response(payload, lang_hint=None) -> list[AudioTurn]`.
  - `turn_id` is `f"turn-{turnId}"`.
  - Keep the raw transcript exactly as received.
  - A malformed payload raises a non-retryable `ProviderError` (convert Pydantic errors).
- **`sam.py`**
  - `parse_sam_output(text, image_sha256) -> list[ImageRegion]`. `region_id` is `f"{image_sha256[:12]}-{object_id}"`, and `c` goes to `confidence`. Malformed input raises `ProviderError`.
  - `top_regions(regions, k=3)` sorts by confidence descending (unscored last), then by `object_id`.
- **`spark.py`**
  - `LabelReading`: Pydantic, `extra="forbid"`, with fields `region_id`, `label_text?`, `inn?`, `strength?` (the schema `Strength`), `readability`, `country?`. `readable` requires `label_text`.
  - `parse_label_json(text, region_id) -> LabelReading`. Invalid JSON or schema raises `ProviderError(retryable=True)`, so that the agent loop retries once.
- **`fixtures.py`:** `FixtureTranscriber(root).transcribe(audio_sha256, lang_hint=None)`, `FixtureSegmenter(root).segment(image_sha256, concept)` and `FixtureLabelReader(root).read(region)`.
  - They read `root/voice/<sha>.json`, `root/sam/<sha>.txt` and `root/label/<region_id>.json`.
  - Each returns `(result, ProviderTrace)`, with `model_id="fixture:<real model id>"`, `cost_usd=0` and a deterministic `call_id`.
  - A missing fixture raises a non-retryable `ProviderError`.
- Define `typing.Protocol` classes `VoiceTranscriber`, `ImageSegmenter` and `LabelReader` with those method signatures. The live Meta adapters will implement them in a later batch.
