# Claim extraction from transcript turns (Muse Spark)

You are the builder for batch 8 of Anamnesis (Python 3.12, uv). Voice Transcribe gives `AudioTurn`s, Spark reads pack labels, and the reconciler compares them. The missing step: turn what the patient **said** into `PatientClaim`s. Model it on `MetaLabelReader` in `anamnesis/providers/meta.py`.

## Goal
Make `tests/contract/test_b8_claims.py` pass, keeping all other tests green. No network in tests.

## Create `anamnesis/providers/claims.py`
- **`CLAIMS_SCHEMA`**: a hand-written **flat** JSON schema (nested objects inline; no `$ref`, no `$defs`).
  - Top level: `{"claims": [claim, ...]}`, `additionalProperties: false`, everything required.
  - Each claim has these fields:
    - `name_text`: string
    - `inn`: string or null
    - `strength`: object-or-null, with `ingredients[{inn, amount (string), unit enum}]`, `per` enum and `release` enum
    - `intake_amount`: object-or-null, `{inn, amount (string), unit enum}`
    - `regimen`: object-or-null, `{units_per_intake: string|null, intakes_per_day: string|null, as_needed: boolean|null}`
    - `status`: enum `active`, `discontinued` or `unknown`
    - `turn_ids`: array of strings
  - Reuse the enum values from the schema enums (`Unit`, `StrengthPer`, `Release`, `MedicationStatus`).
- **`parse_claims_json(text, turns) -> list[PatientClaim]`**
  - `claim_id` is `c1`, `c2`, … in output order.
  - `audio_evidence` is the claim's `turn_ids`. Every id must exist in `turns`, and there must be at least one.
  - Any problem (invalid JSON, wrong shape, unknown or missing turn ids, extra fields, bad enum values) raises `ProviderError("spark", ..., retryable=True)`.
  - Reject extra fields on each raw claim before building the `PatientClaim`.
- **`MetaClaimExtractor(client, guard, model="muse-spark-1.3")`** with `.extract(turns) -> (list[PatientClaim], ProviderTrace | None)`
  - Refuse `*-contributor` models in `__init__` (`ValueError`).
  - No turns → return `([], None)` without any call.
  - Otherwise, inside `with_one_retry`:
    - `guard.check(SPARK_CALL_ESTIMATE_USD)`
    - POST `/chat/completions` (`reasoning_effort: "low"`, `max_tokens: 4000`, `response_format` = json_schema `"patient_claims"`, strict, `CLAIMS_SCHEMA`)
    - charge from `usage`, then parse
  - Format the transcript as one line per turn: `[turn-0 0–8700 ms, speaker A] <transcript verbatim>`.
- **The system prompt is fixed text**, and it must say:
  - Extract every medicine the patient mentions: one claim per medicine.
  - Copy `name_text` exactly as spoken. Fill `inn` only if the patient said the ingredient name; never infer it from a brand.
  - An amount spoken with a frequency ("50 mg twice a day") is an **intake_amount** with `regimen.intakes_per_day`. Use `strength` only when the patient explicitly describes the tablet or pack ("the 5 mg tablets").
  - "I stopped / no longer take" means `discontinued`. Unclear means `unknown`. Leave anything not said as null.
  - Cite the `turn_ids` each claim comes from.
  - Give no medical advice. Only report what the patient said.
- Unit tests of your own in `tests/unit/test_claims_extra.py`.
