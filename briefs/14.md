## 1. Package `anamnesis/agent/` (export `run_intake`, `crop_region`, `AgentAction`)
- **`AgentAction`** (a str enum): `transcribe`, `extract_claims`, `segment`, `read`, `zoom_read`, `reconcile`, `budget_exhausted`.
- **`run_intake(audio, images, *, transcriber, extractor, segmenter, reader, catalogue, language_bias=None, keywords=None, lang_hint=None, concepts=("medicine box", "label"), top_k=3, max_provider_calls=12) -> ReconciliationReport`**
  - `audio` is WAV bytes or `None`. `images` is a list of `(bytes, mime)`.
  - **Fixed order, no LLM chooses actions:**
    1. transcribe, if there is audio;
    2. extract claims, if there are turns;
    3. for each image: segment with each concept in order, **stopping at the first that returns ≥1 region**;
    4. read the `top_regions(k=top_k)` regions;
    5. for each reading that is `unreadable` or `partial`: **one** `zoom_read`. Crop the source image with `crop_region`, then call `reader.read(crop, region, mime=..., cropped=True)`. The new reading keeps the **source** `region_id`. Never call the segmenter on a crop (`max_grounding_iters = 2`: at most 2 reads per region);
    6. reconcile with `reconcile_all`.
  - **Call budget:** each provider call counts as 1. Before a call that would exceed `max_provider_calls`, append a `budget_exhausted` step and skip every remaining provider call. Then still reconcile whatever exists and return a valid report.
  - **No outer retries.** The adapters already retry once. Provider errors become a step whose `outcome` describes the error (no key, no prose from the model). The loop then continues with the next item.
  - Build `PackObservation`s from readings: `observation_id` = `o0, o1, …` in reading order, `visual_evidence = [reading.region_id]`.
  - `spend_usd` = the sum over every returned trace of `cost_usd + prior_cost_usd`. `calls` = the number of provider calls made.
- **`crop_region(image, region, margin=0.10) -> bytes`** (PNG)
  - Raise `ValueError` unless `sha256(image) == region.image_sha256` **and** the decoded size equals `(frame_w, frame_h)`.
  - Pad each side by `int(box_size * margin / 2)`, where the box is inclusive (`x2 - x1 + 1`). Clamp to the frame, then crop.

## 2. `anamnesis/schema/report.py`: `ReconciliationReport` (Pydantic, `extra="forbid"`, not recursive)
- Fields:
  - `intake_id` (a deterministic sha256 of the inputs)
  - `turns: list[AudioTurn]`, `claims: list[PatientClaim]`, `regions: list[ImageRegion]`, `observations: list[PackObservation]`, `findings: list[Finding]`
  - `steps: list[AgentStep]`, with `AgentStep` = `n`, `action: AgentAction`, `target`, `outcome`, `call_ids: list[str]`
  - `calls: int`, `spend_usd: Decimal`
- **Referential checks (M1 #10)**, in a `model_validator`:
  - every `claim.audio_evidence` id is a turn
  - every `observation.visual_evidence` id is a region
  - every finding's evidence ids exist, and its `claim_id` / `observation_id` refer to existing claims and observations
- To avoid an import cycle, define `AgentAction` and `AgentStep` in the schema package and re-export them from `anamnesis.agent`.

## 3. `anamnesis/providers/spend.py`: `SessionGuard(parent, max_usd, max_calls)` and `SessionCapExceeded(SpendCapExceeded)`
- It has the same interface the adapters use: `check`, `charge`, `charge_prechecked`, `charge_estimate`, `total_usd` (session total).
- `check` refuses when the session total plus the estimate exceeds `max_usd`, **or** when `max_calls` calls have already been charged. It then also runs the parent's check.
- Every charge goes through to the parent ledger.

- **#2 Literal or nominal EU strength.** When the salt-basis equivalence applies, accept the **literal** pack amount if the ratio against it is in the accepted set {1, 0.5, 2, 3, 4}; otherwise use the nominal amount. (`Beloc-Zok` 95 vs a 95 mg succinate pack is a match.)
- **#3 Salt words that aren't next to the moiety.** In free text, a salt word that is curated for a moiety (from `INN_ALIASES`) counts as a salt fact when the same text mentions that moiety **or a brand whose single INN is that moiety**, both as whole words: "metoprolol 100 mg tartrate", "Beloc-Zok succinate". Keep the existing one-side conflict rule.
- **#4 Country.** `Catalogue.implied_release(text, country=None)` and `splittable(text, country=None)` resolve with the country. The reconciler passes `pack.country` for pack-side lookups.
