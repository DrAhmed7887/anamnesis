# Arabic-script brands (M2 F-04) and salt-basis equivalence (M2 F-05)

You are the builder for batch 11 of Anamnesis (Python 3.12, uv). Patients in Egypt and Spain say brand names in Arabic. Voice Transcribe spelled the same brands differently on three live runs (`كونكور`, `بلوك زوك`, `البنادول`, or Latin forms), and the catalogue only knows Latin brands. Separately, EU metoprolol succinate packs are labelled 95 mg, which is equivalent to 100 mg tartrate.

## Goal
Make `tests/contract/test_b11_arabic.py` pass, keeping all other tests green. The Arabic claim fixtures are real live outputs.

## Changes
1. **`catalogue.yaml` / `CatalogueEntry`:** add `aliases: tuple[str, ...] = ()`, with a default so existing constructors keep working. Aliases are **brand names**: they carry `release` and `splittable` like the brand itself. Curated aliases:

   | Brand | Arabic aliases |
   |---|---|
   | Concor | كونكور |
   | Beloc-Zok | بيلوك زوك, بلوك زوك |
   | Norvasc | نورفاسك |
   | Glucophage | جلوكوفاج |
   | Panadol | بنادول, بانادول |
   | Panadol Extra | بنادول اكسترا, بانادول اكسترا |
   | Augmentin | اوجمنتين |
   | Lipitor | ليبيتور |

   **Never add partial names** (for example `بيلوك` alone), and never add transliteration rules.
2. **`catalogue.py` `_normalise`**, in this order:
   - casefold
   - drop ®™
   - remove tatweel `ـ` and Arabic diacritics `ً-ٰٟ`
   - unify `أإآٱ → ا`, `ى → ي`, `ة → ه`
   - Arabic-Indic digits → ASCII
   - insert a space at every Arabic↔Latin script boundary (`الPanadol` → `ال panadol`)
   - punctuation → space, then collapse whitespace
   - Apply the same normalisation to the catalogue names.
3. **Arabic clitics:** when the name being matched is in **Arabic script**, allow one optional attached prefix right before it, inside the whole-word boundary: a conjunction or preposition `و`, `ف`, `ب`, `ل` and/or the article `ال` (`ال`, `وال`, `بال`, `فال`, `لل`, `و`, `ب`). The joined-form rule from batch 9 applies to multi-word aliases too (`بيلوكزوك`). Spans still drive containment and ambiguity.
4. **Salt-basis equivalence (F-05):** add a curated `SALT_BASIS_EQUIVALENTS: dict[tuple[str, str, Decimal], Decimal]` in `anamnesis/schema/medication.py`:
   - `("metoprolol", "succinate", 23.75) → 25`
   - `47.5 → 50`
   - `95 → 100`
   - `190 → 200`
   - **Only** when the claim side names **no** salt and the pack ingredient has a salt with a table entry, compare the claim against the **nominal** amount (strength and intake both). Otherwise compare literally.
   - The equivalence must never skip later rules: the formulation gate still applies.
5. **`SPEC.md`:** add one line on Arabic normalisation and clitics, and one on salt-basis equivalence. Add your own unit tests in `tests/unit/test_arabic_extra.py`.
