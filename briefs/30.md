# An `inn` string that names several ingredients is read as that set (SPEC §3, batch 30)

You are the builder for batch 30 of Anamnesis. Read SPEC.md §3, "Identity of one side", first: the bullet "An `inn` that names several ingredients (batch 30)" is the specification. The contract tests are `tests/contract/test_b30_combined_inn.py`.

## Why
Live, the label reader wrote U2's Augmentin pack as `inn` "amoxicillin/clavulanic acid" beside the right 875/125 strength. The reconciler requires a side's scalar `inn` to be one of its strength's ingredients, so it called an extraction conflict and abstained, though the claim matched the pack exactly.

## Build
1. **In `anamnesis/core/reconcile.py`** (the identity of one side, `_identity`): split an `inn` string on "/", "+", "&", ",", or a spaced "and" or «و»; with two or more parts, resolve each as any `inn` is resolved and use the set. With a strength, a named set of two or more must equal the strength's ingredient set, and a single named ingredient must be among them, as now. Without a strength, the named set is the side's identity. A one-part `inn` behaves exactly as today.
2. **Your own tests** go in `tests/unit/test_b30_extra.py`.
