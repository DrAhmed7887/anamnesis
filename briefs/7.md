# Curated salt-to-moiety mapping (SPEC.md §2, §3 rule 9)

You are the builder for batch 7 of Anamnesis (Python 3.12, uv). Live Muse Spark returns ingredient names with their salt ("Bisoprolol fumarate"), while the catalogue uses the active moiety ("bisoprolol"). As a result, the reconciler paired nothing on real readings.

## Goal
Make `tests/contract/test_b7_salts.py` pass, keeping all other tests green.

## Changes
1. **`anamnesis/schema/medication.py`**
   - A curated table `INN_ALIASES: dict[str, tuple[str, str | None]]`, mapping a casefolded alias to `(moiety, salt)`. It covers **only** the catalogue moieties:
     - bisoprolol: fumarate, hemifumarate
     - metoprolol: succinate, tartrate
     - amlodipine: besilate; besylate → salt "besilate"; mesilate; maleate
     - metformin: hydrochloride; "hcl" → "hydrochloride"
     - atorvastatin: calcium; "calcium trihydrate"
     - amoxicillin: trihydrate; sodium
     - clavulanic acid: "potassium clavulanate", "clavulanate potassium" → salt "potassium"
     - paracetamol: "acetaminophen", with no salt
   - `canonical_inn(name)` returns the moiety. `salt_of(name)` returns the salt or `None`.
   - Also accept the label form `"<moiety> (as <alias>)"`, for example `"Clavulanic acid (as potassium clavulanate)"`.
   - **Never strip unknown suffixes:** an unknown name returns its casefolded, trimmed self, with no salt.
   - `IngredientAmount` gets `salt: str | None = None`. Use a `model_validator(mode="before")` that returns a **new** dict, setting `inn` to the moiety and `salt` from the alias when `salt` isn't given. JSON round-trips must stay equal.
   - Export `salt_of` (and `INN_ALIASES`) from `anamnesis.schema`.
   - Remove the hard-coded `acetaminophen` special case in `core/catalogue.py`. Catalogue resolution should match **every** alias of a single-INN entry's moiety, taken from `INN_ALIASES`.
2. **`anamnesis/core/reconcile.py`:** add to the formulation gate (SPEC rule 9): when both sides name a salt for the same canonical ingredient and the salts differ → `formulation_mismatch`.
3. Unit tests of your own in `tests/unit/test_salts_extra.py`.
