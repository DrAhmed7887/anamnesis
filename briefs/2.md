# Catalogue, reconciler and guardrails (SPEC.md §3)

You are the builder for batch 2 of Anamnesis, a Python 3.12 project managed with uv. The schemas from batch 1 are in `anamnesis/schema/`.

## Goal
Make `tests/contract/test_b2_reconcile.py` pass by implementing the deterministic core. Read the "Decision order" in `SPEC.md` §3 first and follow it exactly.

## Files to create
- `anamnesis/core/__init__.py`
- `anamnesis/core/catalogue.yaml`: 8 entries, all synthetic. Each entry has `brand`, `inns` (a list), `countries` (a list) and `synthetic: true`. Exactly these entries:
  - Concor = bisoprolol
  - Beloc-Zok = metoprolol
  - Norvasc = amlodipine
  - Glucophage = metformin
  - Panadol = paracetamol
  - Panadol Extra = paracetamol + caffeine
  - Augmentin = amoxicillin + clavulanic acid
  - Lipitor = atorvastatin
- `anamnesis/core/catalogue.py`:
  - `CatalogueEntry` (frozen) with `brand`, `inns: frozenset[str]`, `countries`, `synthetic`.
  - `Catalogue` with `entries` and `resolve(text, country=None) -> CatalogueEntry | None`.
  - `load_catalogue(path=None)`, which defaults to the YAML next to the module.
  - `resolve` rules:
    - Lowercase the text and remove ®, ™ and punctuation, except `/` and `-` inside words.
    - Match brand names or INN names as whole words. An INN-only match returns the entry whose INN set is exactly that INN.
    - The **longest** matching name wins, so "Panadol Extra" beats "Panadol".
    - No match returns `None`.
- `anamnesis/core/guardrails.py`:
  - `TEMPLATES: dict[DiscrepancyType, str]`: one fixed clinician note per type, neutral and factual ("Patient-reported strength differs from the pack label.").
  - `PATIENT_QUESTIONS: dict[str, str]`: question id → neutral question text.
  - `QUESTION_FOR: dict[DiscrepancyType, str | None]`: `None` for `match`.
  - `class AdviceLeak(Exception)`.
  - `assert_no_advice(text)` raises `AdviceLeak` on advice or instructions about dosing. Use case-insensitive regex with word boundaries:
    - English: "you should", "you must", "take", "increase", "decrease", "reduce", "stop taking", "double", "skip"
    - Spanish: "debe", "tome", "tomar"
    - German: "nehmen sie", "sollten"
  - Every template and question must pass `assert_no_advice` (so write "use", not "take").
- `anamnesis/core/reconcile.py`:
  - `reconcile_pair(claim, observation, catalogue) -> Finding`, following the SPEC decision order.
  - `reconcile_all(claims, observations, catalogue) -> list[Finding]`, following SPEC pairing and leftovers.
  - Finding rules:
    - `finding_id` is `f"{claim_id or '-'}:{observation_id or '-'}"`.
    - The evidence lists are copied from the claim and the pack (an empty list for the missing side).
    - `needs_clinician_review` is true for every type except `match`.
    - `clinician_note = TEMPLATES[type]` and `patient_question_id = QUESTION_FOR[type]`.
  - Convert units to mg with `Decimal`. Compare combinations by INN, and compare ratios with exact `Decimal` arithmetic.
- `tests/unit/test_reconcile_extra.py`: a few edge cases of your own.
