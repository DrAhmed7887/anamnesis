## Part 1: the timeline
1. **`AgentStep`** (`anamnesis/schema/report.py`). Add:
   - `model_id: str | None = None`;
   - `input_tokens`, `output_tokens` and `latency_ms`: ints, default 0, `ge=0`;
   - `cost_usd`: a Decimal, default 0, `ge=0`, `allow_inf_nan=False`.

   Refuse a `model_id` with `-contributor` anywhere in it, in any case, surrounding whitespace ignored.
2. **`IntakeSession`** (`anamnesis/agent/session.py`). Each step records its call:
   - **On success,** from the returned trace: `model_id`, the tokens, `latency_ms`, and `cost_usd = trace.cost_usd + trace.prior_cost_usd`.
   - **On `SpendCapExceeded`, `ProviderError` or `ValueError`,** `cost_usd` is the `charged_usd` the session adds to `spend_usd`. The model, tokens and latency come from the error's `attempt_trace` when it has one.
   - **Steps without a call** keep the defaults.

   So the steps always add up to `spend_usd`.
3. **Templates** (`anamnesis/schema/templates.py`). The contract imports these and pins their exact values:
   - `TIMELINE_HEADING = "How it got here"`;
   - `TIMELINE_COLUMNS = ("#", "Step", "Target", "Outcome", "Model", "Tokens in", "Tokens out", "Time", "Cost")`;
   - `TIMELINE_NONE = "—"`;
   - `TIMELINE_TOTAL = "Total: {calls} calls, ${usd}"`.
4. **The brief** (`anamnesis/brief_html.py`, `anamnesis/brief.py`). Render the collapsed `<details id="timeline">` exactly as SPEC §7 "How it got here" says. Put it after the last `<section>` and before the `<script>`, and escape every value with `_esc`.
