## Create `anamnesis/providers/meta.py`
- **`MetaClient(api_key, base_url="https://api.meta.ai/v1", transport=None, timeout=30.0)`**
  - Wraps an `httpx.Client` and sends `Authorization: Bearer <key>`.
  - `__repr__` must not show the key, and the key must never appear in error messages.
  - HTTP errors map to `ProviderError`: 400, 401, 402, 403 and 404 are non-retryable; 429, 5xx and timeouts are retryable. Include the provider's error message text, never the key.
- **`wav_duration_ms(data) -> int`**, using the stdlib `wave` module.
- **`MetaTranscriber(client, guard)`** with `.transcribe(wav, *, language_bias=None, keywords=None, lang_hint=None) -> (list[AudioTurn], ProviderTrace)`
  - Before any call, validate the audio: RIFF/WAVE, mono, 16-bit, 16 or 24 kHz, at most 10 minutes. Otherwise raise a non-retryable `ProviderError`.
  - `guard.check(cost_usd("muse-voice-transcribe-1.0", audio_ms=duration))` before the call.
  - POST multipart to `/asr/transcribe` with two parts:
    - `request`, of type `application/json`: `{"model": "muse-voice-transcribe-1.0", "audioEncoding": "WAV", "mode": "ENDPOINTING", "languageBias": [...]?, "keywords": [...]?}`
    - `audio`, of type `audio/wav`
  - Parse the response with `parse_transcribe_response`.
  - Cost comes from `audioDurationMs`. Then `guard.charge(trace)`.
- **`MetaSegmenter(client, guard)`** with `.segment(image, concept, *, mime) -> (list[ImageRegion], ProviderTrace)`
  - The concept must be ONE short noun phrase: non-empty, at most 4 words, no commas, no " and " / " or ". Otherwise raise `ProviderError` before any call.
  - `guard.check($0.0025)`.
  - POST JSON to `/responses`:
    - `{"model": "sam-3.1", "input": [{"type": "message", "role": "user", "content": [{"type": "input_text", "text": concept}, {"type": "input_image", "image_url": "data:<mime>;base64,<...>"}]}], "metadata": {"include_confidence": "true"}}`
  - The text is the concatenation of every `output[].content[]` item where `type == "output_text"`.
  - Parse it with `parse_sam_output(text, image_sha256=sha256(image))`. `call_id` is the response `id`. Charge the guard.
- **`MetaLabelReader(client, guard, model="muse-spark-1.3")`** with `.read(image, region, *, mime) -> (LabelReading, ProviderTrace)`
  - Refuse `*-contributor` models in `__init__` with `ValueError`.
  - Pre-call `guard.check(SPARK_CALL_ESTIMATE_USD)`, where `SPARK_CALL_ESTIMATE_USD = Decimal("0.03")`.
  - POST to `/chat/completions` with `model`, `reasoning_effort: "low"`, `max_tokens: 4000`, and a fixed system prompt. The prompt tells the model:
    - read only what is printed on the pack inside the given box
    - give no advice
    - use `unreadable` or `partial` rather than guessing
  - The user message has the image as a data URL plus text stating the box: `x1=…, y1=…, x2=…, y2=…` on a `w×h` image.
  - `response_format = {"type": "json_schema", "json_schema": {"name": "label_reading", "strict": true, "schema": LABEL_SCHEMA}}`.
    - `LABEL_SCHEMA` is a **hand-written flat schema**: nested objects inline, no `$ref`, no `$defs`.
    - Fields: `label_text`, `inn` and `country` as string-or-null. `readability` as an enum. `strength` as object-or-null, holding `ingredients[{inn, amount (string), unit enum}]`, `per` enum and `release` enum.
  - Parse with `parse_label_json(content, region.region_id)`.
  - Cost comes from `usage.prompt_tokens` and `usage.completion_tokens`.
  - The whole call-parse-charge sequence is wrapped in `with_one_retry`, so an invalid JSON reply is paid for and retried once.
- Export the new names from `anamnesis.providers.meta` (they don't need to be in `providers/__init__`).
