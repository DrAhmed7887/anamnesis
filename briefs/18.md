## Changes
1. **Crop-first reads.** In `_read_photo`, for each region from `top_regions`: once `session.exhausted` is true, skip the region (no crop, no step). Otherwise cut `crop_region(image[0], region)`. If it raises `ValueError`, log `session.note(AgentAction.READ, region.region_id, "error: crop failed")` and skip the region: no provider call, no reading. Otherwise read the crop inside `session.call` as today: `reader.read(crop, region, mime="image/png", cropped=True)`. Cut the crop outside the `session.call` lambda, so a failed crop never counts as a provider call.
2. **The 2x zoom.** `_zoom(session, reader, image, region, reading)` keeps its signature (a contract calls it directly) and its existing checks: the exhausted check first, then the "error: crop failed" note, then the region-id check on the new reading. It re-cuts the same crop with `crop_region(image[0], region)` and enlarges it by `min(2, 2048 / longest side)` with Lanczos, as PNG. If that factor is ≤ 1, return the reading unchanged, with no step and no call. Put the enlarging in a small function in `crop.py`, which loop.py calls on the crop. Both cuts go through the name `crop_region` in `anamnesis/agent/loop.py`, because the contracts patch `anamnesis.agent.loop.crop_region`.
3. **`spark_call_estimate(body) -> Decimal`** in `meta.py`, exported in `__all__`. It adds up the characters of every text in `body["messages"]`: a string `content`, and the `text` of each `{"type": "text"}` part. It takes 5,000 input tokens per `{"type": "image_url"}` part and `body["max_tokens"]` output tokens, and returns `cost_usd(body["model"], input_tokens=chars // 2 + 5000 * images, output_tokens=max_tokens)`.
4. **Use it.** In `MetaLabelReader.read` and `MetaClaimExtractor.extract`, compute the estimate once from the request body. Pass it to `self.guard.check(...)` in each attempt and as `estimate=` to `with_one_retry`. Remove `SPARK_CALL_ESTIMATE_USD`, which nothing else uses.
5. **Claim extraction asks for `max_tokens: 16000`.** Label reads stay at 4000.
6. **Length stops.** In both adapters, right after `self.guard.charge_prechecked(trace)` and before parsing the content, a reply whose `choices[0]["finish_reason"] == "length"` raises `ProviderError("spark", <a short fixed message>, retryable=False, attempt_trace=trace)`. `with_one_retry` then records its call id and real cost and does not retry. The message must not include the model's text.
7. **Unit tests.** Update the unit tests that assumed a full-photo first read or the fixed $0.03 estimate, for example `tests/unit/test_m3_blockers_extra.py::test_a_paid_spark_reply_with_an_empty_id_is_counted` (line 119: the two charges are now that call's bound, so compute it with `spark_call_estimate`), and any others the suite shows. Put your own new unit tests in `tests/unit/test_crops_extra.py`.
